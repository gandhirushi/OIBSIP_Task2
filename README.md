# OIBSIP_Task2

Data Science Project:- Unemployment Analysis with Python

This work was completed as part of my internship at Oasis Infobyte, where I gained hands-on experience in applying data science techniques to real-world problems.

Unemployment is a key economic indicator, measured as the percentage of people who are unemployed within the total labour force. The COVID-19 pandemic led to a significant rise in unemployment rates, making it an important area for data-driven analysis.

In this project, I developed a data analysis dashboard to study unemployment trends in India, focusing on the impact of hashtag#COVID-19 and regional variations. The goal was to extract meaningful insights from data and present them in an interactive and visual format.

The project includes:
1)Analysis of unemployment rate trends over time
2)Comparison of pre-COVID and during-COVID unemployment levels
3)Region-wise unemployment distribution
4)Relationship between labour participation and unemployment rate
5)Using tools such as Python, Pandas, and Plotly, I built an interactive 6)dashboard that allows users to filter data by region and area, enabling deeper exploration of patterns and trends.

This project helped me strengthen my skills in data cleaning, visualization, and building user-friendly dashboards using Streamlit.
